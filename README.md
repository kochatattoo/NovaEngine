# NovaEngine — Match3 Demo

Демонстрационная игра Match3 на собственном движке NovaEngine.

## Соответствие тестовому заданию

### 1. Логика
- **Поле 10×10** — реализовано в `Match3Board` (ROWS=10, COLS=10).
- **Удаление 3+ кристаллов в ряд** — метод `FindMatches` находит все горизонтальные и вертикальные цепочки длиной ≥3. `RemoveTiles` удаляет их.
- **Гравитация** — `ApplyGravity` сдвигает плитки вниз, заполняя пустоты.
- **Заполнение новыми случайными кристаллами** — `FillEmpty` добавляет новые случайные плитки (0..5).
- **Специальные камни (предусмотрены, но не реализованы)** — `enum class TileType` содержит зарезервированные значения `SpecialBomb`, `SpecialRainbow`, что архитектурно позволяет их внедрить в будущем без переделки логики.

### 2. Визуализация и интерфейс
- **Визуализация поля** — реализована в графическом виде: цветные спрайты, 6 уникальных цветов (вместо букв A–F). Цвета соответствуют типам плиток (0–5).
- **Ввод** — выполнен мышью: клик на плитку и перетаскивание на соседнюю. Консольный ввод (`m x y d`) может быть добавлен поверх существующего через обработку клавиатурных событий, но для демонстрации выбран более интуитивный способ.
- **Выход** — клавиша `Escape` закрывает приложение (соответствует `q`).

### 3. Техническое
- **Язык и окружение** — C++17, Lua 5.4, OpenGL 3.3 Core. Игра работает как оконное приложение Windows.
- **ООП** — модель (`Match3Board`) отделена от визуализации (Lua-скрипты). Используется компонентная система (`GameObject`, `SpriteRenderer`, `Transform`).
- **Интерфейс модели** содержит все требуемые методы:
  - `init()` → `board:FillRandom()` создаёт поле и заполняет случайными плитками.
  - `tick()` → реализован как последовательность `FindMatches()` → `RemoveTiles()` → `ApplyGravity()` → `FillEmpty()`. Вызывается автоматически после хода.
  - `move(from, to)` → `board:Swap()` меняет две плитки. У нас `Swap` вызывается явно, а затем вручную выполняется `tick`. Для соответствия можно обернуть в единый `Move(row1,col1,row2,col2)`, который внутри делает Swap и Tick.
  - `mix()` → `board:Mix()` перемешивает поле (реализовано как перезаполнение без начальных троек).
  - `dump()` → может быть легко реализован как вывод в лог типов плиток (в текущей версии не вызывается, но архитектура позволяет).
- Основной цикл: ожидание ввода, обмен, каскадная обработка `tick` до стабилизации, проверка `HasPossibleMoves`, при необходимости `Mix`.

## Запуск и сборка
- Откройте `NovaEngine.sln` в Visual Studio 2022.
- Убедитесь, что в настройках пост-события проекта Sandbox прописано копирование папки `assets`:  
  `cmd /c xcopy /y /d "$(ProjectDir)assets" "$(OutDir)assets\"`
- Соберите решение (F7) и запустите (F5).

## Структура репозитория
- `Engine/` — статическая библиотека движка.
- `Sandbox/` — исполняемый проект игры.
  - `Sandbox/assets/scripts/` — Lua-скрипты (копируются в выходную папку при сборке).
  - `Sandbox/assets/textures/` — текстуры.
  - `Sandbox/assets/fonts/` — шрифты.
