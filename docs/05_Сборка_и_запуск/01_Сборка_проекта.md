# 01 — Сборка проекта

> **Статус:** 🟢 Актуально для v0.1

## Требования

| Что | Минимум | Рекомендуется |
|---|---|---|
| **OS** | Windows 10 | Windows 10/11 |
| **IDE** | Visual Studio 2019 | Visual Studio 2022 (v17.x) |
| **C++** | C++17 | C++20 (для будущих фич) |
| **MSVC** | v142 | v143 |
| **vcpkg** | — | установлен и в PATH |
| **Платформа** | Win32 / x86 | x64 |

> ⚠️ **Только Windows.** Linux/macOS не поддерживаются в v0.1.

## Подготовка

### 1. Установить Visual Studio 2022

- Скачать: <https://visualstudio.microsoft.com/>
- При установке выбрать workloads:
  - **"Desktop development with C++"**
  - **"Game development with C++"** (опционально, для будущего)

### 2. Установить vcpkg

Если ещё нет:

```powershell
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg integrate install
```

### 3. Установить glm

```powershell
vcpkg install glm:x64-windows
```

Это автоматически установит `x86-windows` тоже (multi-target triplet).

## Клонирование и открытие

```powershell
git clone <repo-url> NovaEngine
cd NovaEngine
```

Открыть `NovaEngine.sln` в Visual Studio. Структура:

- **Engine** — статическая библиотека (`Engine.lib`).
- **SandBox** — исполняемое приложение (`SandBox.exe`).

## Конфигурации

В Visual Studio доступны 4 конфигурации (Debug/Release × x86/x64). Рекомендуемая для разработки: **Debug | x64**.

| Конфигурация | Платформа | Что собирается |
|---|---|---|
| Debug | x64 | `Engine.lib` + `SandBox.exe` с отладочными символами |
| Debug | Win32 | то же, 32-бит |
| Release | x64 | `Engine.lib` + `SandBox.exe` оптимизированный |
| Release | Win32 | то же, 32-бит |

### Выбор конфигурации

В Visual Studio: **Build → Configuration Manager** (или выпадающий список на тулбаре).

## Сборка

### Из IDE

1. **Build → Build Solution** (`Ctrl+Shift+B`).
2. Если ошибка про `glm/glm.hpp` — проверьте, что vcpkg installed (`vcpkg install glm:x64-windows`).
3. Если ошибка про `Lua/lua.h` — проверьте, что `Libraries/lua/src/` существует (исходники Lua 5.4 включены в репо).

### Из командной строки

```powershell
msbuild NovaEngine.sln /p:Configuration=Debug /p:Platform=x64
```

Или с Ninja (если установлен):

```powershell
cmake -B build -G Ninja .
cmake --build build
```

> ⚠️ CMake пока не добавлен в репо. Только MSBuild / vcxproj.

## Запуск

### Из IDE

1. Правой кнопкой по проекту `SandBox` → **Set as Startup Project**.
2. **Debug → Start Debugging** (`F5`) или **Start Without Debugging** (`Ctrl+F5`).

Sandbox должен запуститься в окне 1280×720, в консоли будут логи `NK_CORE_INFO`.

### Из командной строки

После `Build Solution` артефакты лежат в:

```
D:\ENGINE\NovaEngine\x64\Debug\
├── Engine.lib
├── SandBox.exe
├── opengl32.dll (если есть в PATH)
├── assets/
│   ├── scripts/
│   │   ├── game.lua
│   │   ├── game_match3.lua
│   │   └── ui_test.lua
│   ├── textures/test.png
│   ├── ui/button.png
│   └── fonts/{arial.ttf, Samson.ttf}
└── ...
```

Запуск:

```powershell
cd D:\ENGINE\NovaEngine\x64\Debug
.\SandBox.exe
```

> ⚠️ **CWD важен.** `SandBox.exe` ищет `assets/scripts/game_match3.lua` относительно CWD. Если запустить из другого места — `Log("Script loaded: game_match3.lua")` не появится, будет `Failed to load font` и т.д.

## Post-build event

`SandBox.vcxproj` имеет post-build step:

```bat
cmd /c xcopy /y /d "$(ProjectDir)assets" "$(OutDir)assets\"
```

Копирует `SandBox/assets/` в `x64/Debug/assets/` (или `x64/Release/`). Флаг `/y` — overwrite без подтверждения. `/d` — копировать только более новые файлы.

Если при сборке видите `1 файл(ы) скопирован`, значит post-build сработал. Если 0 — обычно значит, что папка `assets/` не найдена (проверьте, что она есть в `SandBox/`).

## Типичные ошибки

| Ошибка | Решение |
|---|---|
| `Cannot open include file: 'glm/glm.hpp'` | `vcpkg install glm:x64-windows` |
| `Cannot open include file: 'sol/sol.hpp'` | Проверьте, что `Libraries/sol/` не пустая |
| `Cannot open include file: 'EnTT/entt/entt.hpp'` | Проверьте `Libraries/EnTT/entt/entt.hpp` |
| `LNK2019: unresolved external symbol main` | Убедитесь, что `Game.cpp` в проекте `SandBox` подключён и в нём есть `#include <Core/EntryPoint.h>` |
| `glad_gl* undefined` | Проверьте, что `Engine/Source/glad/gl.c` добавлен в `Engine.vcxproj` |
| `Linker error: opengl32.lib` | Добавьте в Additional Dependencies SandBox: `opengl32.lib` |
| `assets\scripts\game_match3.lua не найден` | Проверьте post-build, проверьте CWD |

## Конфигурация через `EngineConfig`

По умолчанию окно 1280×720, заголовок "NovaEngine Sandbox". Чтобы изменить, отредактируйте `Engine/Include/Core/EntryPoint.h`:

```cpp
NK::EngineConfig config;
config.Title  = "My Game";
config.Width  = 1920;
config.Height = 1080;
```
