# 02 — Активы и ресурсы

> **Статус:** 🟢 Актуально для v0.1

## Где лежат ассеты

Все ассеты Sandbox лежат в `SandBox/assets/`:

```
SandBox/assets/
├── scripts/
│   ├── game.lua              # демо: игрок + UI текст + UI кнопка
│   ├── game_match3.lua       # основной скрипт Match3 (Match3Game::Start грузит его)
│   └── ui_test.lua           # минимальный тест UI
├── textures/
│   └── test.png              # 32×32 placeholder
├── ui/
│   └── button.png            # заготовка для кнопки
└── fonts/
    ├── arial.ttf             # основной шрифт
    └── Samson.ttf            # запасной
```

## Как они попадают в `$(OutDir)`

`SandBox.vcxproj` post-build event:

```bat
cmd /c xcopy /y /d "$(ProjectDir)assets" "$(OutDir)assets\"
```

Копирует всю папку `assets\` в `x64/Debug/assets/` (или `x64/Release/`). После сборки артефакт `SandBox.exe` лежит **рядом** с папкой `assets/`, и все пути в Lua-скриптах относительны CWD.

## Пути в коде и скриптах

### C++

```cpp
// В Engine
NK_CORE_INFO("Engine initialized.");   // не зависит от путей

// В Match3Game
m_ScriptPath = "assets/scripts/game_match3.lua";
```

### Lua

```lua
local tex = GetTexture("assets/textures/test.png")
local font = LoadFont("assets/fonts/arial.ttf")
local shader = GetShader("SpriteShader", vSrc, fSrc)
```

Все пути — **относительно CWD**. Если запустить `SandBox.exe` из `x64/Debug/`, путь `assets/scripts/game.lua` корректен.

## Форматы

| Тип | Поддерживаемые форматы | Загрузчик |
|---|---|---|
| **Текстуры** | PNG, JPG, TGA, BMP | `stb_image` (`stbi_load`) |
| **Шрифты** | TTF (TrueType) | `stb_truetype` (`stbtt_InitFont`) |
| **Шейдеры** | GLSL 330 (строкой) | `Shader(vertexSrc, fragmentSrc)` |

## Как добавить новый ассет

### 1. Текстура

1. Положить файл в `SandBox/assets/textures/my_tex.png`.
2. Пересобрать проект (post-build скопирует).
3. Использовать:
   ```lua
   local tex = GetTexture("assets/textures/my_tex.png")
   ```

### 2. Шрифт

1. Положить `.ttf` в `SandBox/assets/fonts/`.
2. Пересобрать.
3. Использовать:
   ```lua
   local font = LoadFont("assets/fonts/my_font.ttf")
   ```

### 3. Lua-скрипт

1. Положить `.lua` в `SandBox/assets/scripts/`.
2. Пересобрать.
3. Запустить: либо изменить `m_ScriptPath` в `Match3Game.cpp`, либо создать новую игру (см. [04_Sandbox_и_Match3/01_Архитектура_Sandbox](../04_Sandbox_и_Match3/01_Архитектура_Sandbox.md)).

## Размер и оптимизация

- **Текстуры:** должны быть степенью 2 (32, 64, 128, 256, 512, 1024, 2048) для производительности, хотя движок сейчас это не проверяет.
- **Шрифты:** большие TTF (>5MB) будут медленно грузиться. Для UI лучше иметь несколько готовых bitmap-шрифтов.
- **Lua-скрипты:** загружаются один раз при старте. Размер не критичен.
