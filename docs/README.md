Документация **текущего состояния** движка NovaEngine. Описывает архитектуру,

Документация **пути создания** (история решений, рефакторингов и граблей) лежит
отдельно в папке [`Путь создания`](../Путь%20создания/) — это нарратив,
который привёл проект к v0.1. Текущий набор — это **системный справочник**:
что есть, как работает, как использовать, что делать дальше.

## 🧱 Состояние проекта одной строкой

NovaEngine v0.1 — это **учебный игровой движок на C++17 / OpenGL 3.3 Core / Lua 5.4 (через sol2) / EnTT ECS** под Windows. Реализованы окно, графический контекст, событийный ввод, 2D-рендерер со спрайтами и текстом (stb_truetype), ортографическая камера, сцена с GameObject-компонентами, UI с якорями и кнопками, ResourceManager, полный Lua-биндинг и демо-игра Match3 (10×10 поле, поиск и каскады совпадений, ввод мышью). **Параллельно идёт миграция на ECS** — каркас `World` уже есть, но в Sandbox пока не используется.
