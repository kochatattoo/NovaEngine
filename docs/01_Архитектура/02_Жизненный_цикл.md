# 02 — Жизненный цикл приложения

> **Статус:** 🟢 Актуально для v0.1

Этот документ описывает полный путь от запуска `.exe` до выхода, и что происходит в каждой точке.

## Точка входа

`Engine/Include/Core/EntryPoint.h` содержит скрытый `main()` (только для `_WIN32`):

```cpp
int main(int argc, char** argv) {
    NK::EngineConfig config;
    config.Title  = "NovaEngine Sandbox";
    config.Width  = 1280;
    config.Height = 720;

    NK::Engine engine(config);
    auto app = NK::CreateApplication();
    engine.Run(app);
    delete app;
    return 0;
}
```

Игра **не пишет `main()`** — она подключает `EntryPoint.h` ровно один раз (в `Sandbox/Source/Game.cpp`) и реализует `CreateApplication()`.

## `Engine::Run` — главный цикл

```cpp
void Engine::Run(Application* app) {
    m_App = app;
    Initialize();          // 1. Поднять окно, контекст, биндинги Lua
    m_Scene.OnStart();     // 2. Сцена создаёт объекты, вызывает OnStart
    m_App->OnStart();      // 3. Игровая логика: создать Match3Game, загрузить Lua
    m_Running = true;

    Timer timer;
    while (m_Running) {
        float dt = timer.Tick();   // 4. Измерить dt

        m_Window->OnUpdate();                  // 4a. PeekMessage, обработка WM_*
        if (m_Window->ShouldClose()) m_Running = false;

        InputSystem::Get().Update();           // 4b. Разобрать очередь событий
                                              //     заполнить карты "нажато/отпущено"

        ctx->MakeCurrent();
        Renderer::BeginFrame();                // 4c. Очистить экран
        m_Scene.OnUpdate(dt);                  // 4d. Обновить все GameObject в сцене
        m_App->OnUpdate(dt);                   // 4e. Игровая логика
        Renderer::EndFrame();                  // 4f. (пока пусто, зарезервировано)
        ctx->SwapBuffers();                    // 4g. Показать кадр
    }

    m_App->OnShutdown();                       // 5. Лог "shutting down"
    Shutdown();                                // 6. m_Running=false (окно уже само разрушится в ~Window)
}
```

## Что происходит в `Initialize()`

1. `SetConsoleOutputCP(CP_UTF8)` — консоль в UTF-8.
2. Создаётся `Window` (WinAPI, `WS_OVERLAPPEDWINDOW`, `WM_NCCREATE` сохраняет `this` в `GWLP_USERDATA`).
3. Окно само создаёт `GraphicsContext` (`GraphicsContext::Create(HWND)` → реализация `WindowsOpenGLContext`).
4. Контекст `Init(HWND)`:
   - выбирает `PIXELFORMATDESCRIPTOR` с поддержкой OpenGL,
   - создаёт временный контекст,
   - достаёт `wglCreateContextAttribsARB` для контекста 3.3 Core,
   - пересоздаёт постоянный контекст,
   - вручную (без автозагрузчика glad) получает **все** используемые GL-функции через `GetAnyGLFuncAddress` и сохраняет в `glad_gl*` указатели.
5. `Renderer::Init()` — включает `GL_DEPTH_TEST`, `GL_CULL_FACE` (по умолчанию).
6. `SetupLuaBindings()` — регистрирует все движковые классы/функции/enum'ы в `LuaManager`.
7. Создаётся `DefaultSprite` (вершинный/фрагментный шейдеры для спрайтов) и кладётся в `ResourceManager`.
8. Назначается `ResizeCallback` окну:
   - `m_Scene.GetGameCamera().OnWindowResized(w,h)`,
   - `m_Scene.GetUICamera().SetProjection(0, w, h, 0)`,
   - `glViewport(0,0,w,h)`,
   - `m_Scene.RecalculateAnchors(w,h)` — пересчитать UI-якоря.

## `OnStart` игры

В `Match3Game::Start()`:
1. `m_Lua.RunScript("assets/scripts/game_match3.lua")` — выполнить весь файл.
2. `m_Lua.CallFunction("OnStart")` — вызвать Lua-функцию `OnStart()`.

В `GameObject::OnStart` для каждого объекта:
- `SpriteRenderer::OnStart` — закэшировать `s_QuadVAO/s_QuadVBO` (создаются один раз).
- `TextRenderer::OnStart` — то же.
- `ScriptComponent::OnStart` — выполнить свой Lua-скрипт.
- `Button::OnStart` — найти `SpriteRenderer` и `TextRenderer` в том же объекте.

## Кадр — `OnUpdate`

Каждый кадр у игры `Match3Game::Update(dt)`:
1. `m_Lua.CallFunction("OnUpdate", dt)` — Lua-скрипт обрабатывает мышь, делает Swap, каскады, и т.д.

У сцены `Scene::OnUpdate(dt)`:
- По всем `m_Objects` (игровые) → `obj->OnUpdate(dt)` → все компоненты.
- По всем `m_UIObjects` (UI) → `obj->OnUpdate(dt)` → все компоненты.

`Renderer::BeginFrame()`:
- `glClearColor(...)` (по умолчанию чёрный, можно переопределить `SetClearColor`).
- `glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)`.

`Scene::OnRender()`:
- Игровые объекты: `m_GameCamera.GetViewProjectionMatrix()` → `SpriteRenderer::Render(viewProj)`.
- UI-объекты: сортировка по `ZOrder` → `glDisable(GL_DEPTH_TEST)`, `glEnable(GL_BLEND)`, `glBlendFunc(SRC_ALPHA, ONE_MINUS_SRC_ALPHA)`, `glDisable(GL_CULL_FACE)` → рендер спрайтов и текста через `m_UICamera.GetViewProjectionMatrix()` → восстановление state.

## Завершение

`m_Window->ShouldClose()` срабатывает в `WM_CLOSE`. В главном цикле `m_Running = false`, выходим из `while`. Дальше:

1. `m_App->OnShutdown()` — у Sandbox `NK_INFO("Sandbox shutting down.")`.
2. `Engine::Shutdown()` — `m_Running=false`, лог "Engine shutdown complete".
3. `~Engine()` → `s_Instance = nullptr`.
4. `~Window()` → `DestroyWindow(m_Hwnd)`, `m_GraphicsContext->Shutdown()` (wglDeleteContext).
5. `delete app` (в `main`) — уничтожение `SandboxApp` → `m_Game.reset()` → `~Match3Game`.
6. `return 0`.

## Гарантии и инварианты

- **Один вызов `OnStart` / `OnShutdown` на приложение** — гарантируется порядком в `Run`.
- **`OnUpdate` вызывается ровно один раз за кадр**, всегда с положительным `dt`.
- **Если `OnStart` бросит исключение** — `~Engine` всё равно сработает, `s_Instance` обнулится. Исключение пробросится в `main`, который упадёт без `try` (текущее поведение). TODO: try/catch в `Run`.
- **Lua-состояние переживает кадры** — `LuaManager` хранится в `Engine`, скрипты не перезагружаются между кадрами.
- **GameObject, созданный в `OnStart` после флага `m_Started = true`, получает свой `OnStart` сразу** — это обработано в `Scene::CreateGameObject`.

## Диаграмма последовательности

```
main()                         Engine::Run                     Application::OnStart
  │                                │                                  │
  ├── Engine engine(config) ──────►│                                  │
  ├── auto app = CreateApp() ──────┼─────────────────────────────────►│
  ├── engine.Run(app) ─────────────┤                                  │
  │                                ├── Initialize()                   │
  │                                │     ├─ Window::Init              │
  │                                │     ├─ ctx->Init (3.3 Core)      │
  │                                │     ├─ Renderer::Init            │
  │                                │     ├─ SetupLuaBindings()        │
  │                                │     └─ DefaultSprite (Resource)  │
  │                                ├── scene.OnStart()                │
  │                                ├── app->OnStart() ────────────────┼── (Match3Game::Start)
  │                                │                                  │     ├─ Lua.RunScript
  │                                │                                  │     └─ Lua.Call("OnStart")
  │                                │                                  │
  │                                ╔═════════ frame loop ════════════╗
  │                                ║ m_Window->OnUpdate()            ║
  │                                ║ InputSystem::Get().Update()     ║
  │                                ║ Renderer::BeginFrame()          ║
  │                                ║ scene.OnUpdate(dt)              ║
  │                                ║ app->OnUpdate(dt) ──────────────┼── (Match3Game::Update)
  │                                ║                                 ║     └─ Lua.Call("OnUpdate", dt)
  │                                ║ scene.OnRender()                ║
  │                                ║ Renderer::EndFrame()            ║
  │                                ║ ctx->SwapBuffers()              ║
  │                                ╚═════════════════════════════════╝
  │                                ├── app->OnShutdown()
  │                                └── Shutdown()
  ◄────────────────────────────────┘
  delete app
  return 0
```

## Где обработка исключений

- ❌ `Engine::Run` — **не оборачивает `try/catch`**. Исключение из пользовательского `OnUpdate` убьёт процесс. TODO v0.2.
- ❌ `LuaManager::CallFunction` — оборачивает `sol::protected_function_result` и логирует ошибку, но **возвращает broken result** вызывающему. Игры должны сами проверять.
- 🟡 `Input::IsKeyDown` — если `Window` не создан, вернёт `false` (проверка HWND внутри).
