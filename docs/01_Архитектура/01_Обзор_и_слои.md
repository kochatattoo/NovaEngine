# 01 — Обзор и слои

> **Статус:** 🟢 Актуально для v0.1

## Что такое NovaEngine

NovaEngine — **учебный игровой движок общего назначения**, разрабатываемый одним человеком. Написан на C++17, опирается на OpenGL 3.3 Core, скриптуется на Lua, имеет ECS-каркас на EnTT. Целевая платформа сейчас — **Windows** (WinAPI + WGL), кроссплатформенность заложена абстракцией `GraphicsContext`, но пока не реализована.

**Демо-проект — игра Match3** (поле 10×10, полный геймплей с поиском и каскадами совпадений, гравитацией, перемешиванием). Это «reference game» — на ней обкатываются все системы движка.

## Принципы

1. **Разделение движок / игра.** Движок — статическая библиотека `Engine.lib`, не знает про конкретные игры. Игра (`Sandbox.exe`) — отдельный исполняемый проект, наследует `NK::Application` и реализует фабрику `CreateApplication()`.
2. **Application — это `MonoBehaviour`.** У игры есть один глобальный объект-приложение с виртуальными методами `OnStart`, `OnUpdate(dt)`, `OnShutdown`. Движок сам решает, когда их вызвать.
3. **Lua — основной язык игровой логики.** Игры пишутся в скриптах и подключаются через `LuaManager`. C++ нужен только для новых движковых систем.
4. **Scene + GameObject + Component — основная модель объектов.** Всё, что существует в игре, — это `GameObject` с набором `Component`. Ведётся параллельный ECS-каркас для перехода на data-oriented модель.
5. **Ортографическая 2D-камера + 2D-сцена как приоритет.** Движок сейчас чисто 2D, 3D-возможности (перспективная `Camera`) сохранены, но не развиваются.
6. **Минимум магии, максимум читаемости.** Прямые вызовы, простые контейнеры, никаких шаблонных SFINAE-лабиринтов, кроме одного места (`EventDispatcher`).

## Слои архитектуры

Движок логически делится на **6 слоёв** (от низкого к высокому):

```
┌──────────────────────────────────────────────────────────────┐
│  Sandbox (Match3)         ← игра, скрипты Lua                │
├──────────────────────────────────────────────────────────────┤
│  Lua-интеграция           ← LuaManager + биндинги            │
├──────────────────────────────────────────────────────────────┤
│  Игровой слой             ← Scene, GameObject, Components,   │
│                            ECS World, UI, ResourceManager    │
├──────────────────────────────────────────────────────────────┤
│  Рендер-слой              ← Renderer, SpriteRenderer,        │
│                            TextRenderer, Shader, Font,       │
│                            Texture2D, камеры                  │
├──────────────────────────────────────────────────────────────┤
│  Платформенный слой       ← Window, GraphicsContext,         │
│                            Input, Event                      │
├──────────────────────────────────────────────────────────────┤
│  Core                     ← Engine, Application,             │
│                            EntryPoint, Timer, Log            │
└──────────────────────────────────────────────────────────────┘
```

| Слой | Назначение | Ключевые классы |
|---|---|---|
| **Core** | Запуск движка, главный цикл, лог, таймер, контракт с игрой | `Engine`, `Application`, `EntryPoint`, `Log`, `Timer` |
| **Платформенный** | Окно OS, ввод, события, графический контекст | `Window`, `GraphicsContext`, `Input`, `InputSystem`, `Event`, `EventDispatcher` |
| **Рендер** | Отрисовка спрайтов и текста, шейдеры, камеры | `Renderer`, `Shader`, `Texture2D`, `Font`, `VertexArray/Buffer/IndexBuffer`, `Camera`, `OrthographicCamera`, `SpriteRenderer`, `TextRenderer` |
| **Игровой** | Сцена, объекты, компоненты, ECS, UI, ресурсы | `Scene`, `GameObject`, `Component`, `Transform`, `ScriptComponent`, `ECS::World`, `ECS::TransformComponent`, `ECS::SpriteComponent`, `Button`, `Anchor`, `ResourceManager`, `ResourcePool` |
| **Lua-интеграция** | Скриптинг, экспорт API | `LuaManager`, `LuaBindings`, `LuaClassBindings`, `LuaComponentBindings`, `LuaCameraBindings`, `LuaFuncBindings`, `LuaInputBindings` |
| **Sandbox** | Конкретная игра, демонстрирующая API | `SandboxApp`, `Match3Game`, `Match3Board`, `assets/scripts/*.lua` |

## Имена, namespace, конвенции

- **Namespace** — `NK` (от **N**ova**K**ernel, историческое). Подмодули — `NK::ECS`.
- **Класс движка** — `NK::Engine` (singleton через `Engine::Get()`).
- **Класс приложения** — `NK::Application` (базовый; игра наследует и переопределяет).
- **Префикс логгера** — `NK_` для клиентского (игры), `NK_CORE_` для движкового.
- **Клавиши** — `enum class KeyCode : uint32_t` (буквы = ASCII, F-клавиши = VK_F*).
- **Мышь** — `enum class MouseButton : uint8_t`.
- **Имена файлов** — соответствуют имени класса, без префикса `C` (C++-style, не MFC).

## Что НЕ входит в v0.1 (осознанные ограничения)

- ❌ Кроссплатформенность (только Windows).
- ❌ 3D-пайплайн (перспективная `Camera` сохранена, но не используется).
- ❌ Звук.
- ❌ Сетевой код.
- ❌ Физика.
- ❌ Скриптовые корутины (асинхронность).
- ❌ Горячая перезагрузка скриптов.
- ❌ Сериализация сцен.
- ❌ Полноценная интеграция ECS в Sandbox (только каркас).
- ❌ Многопоточность (всё в одном потоке, OpenGL контекст — основной).
