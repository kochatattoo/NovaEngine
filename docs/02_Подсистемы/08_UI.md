# 08 — UI (Anchor, Button)

> **Статус:** 🟢 Стабильно, базовый UI работает

**Файлы:**
- `Engine/Include/UI/Anchor.h`, `Engine/Source/UI/Anchor.cpp`
- `Engine/Include/UI/Button.h`, `Engine/Source/UI/Button.cpp`

UI — это **отдельный набор GameObject** в `Scene::m_UIObjects`, рендеримый отдельной камерой (`m_UICamera`, top-left origin) с включённым блендингом. Два базовых компонента: `Anchor` (привязка) и `Button` (интерактив).

## Класс `Anchor`

**Файл:** `Engine/Include/UI/Anchor.h`

```cpp
enum class AnchorPreset {
    TopLeft, TopCenter, TopRight,
    MiddleLeft, MiddleCenter, MiddleRight,
    BottomLeft, BottomCenter, BottomRight,
    StretchAll
};

class Anchor : public Component {
public:
    Anchor(GameObject* owner);
    void SetPreset(AnchorPreset preset);
    void SetScreenAnchor(float sx, float sy);
    void SetObjectAnchor(float ox, float oy);
    void SetSize(const glm::vec2& size);
    void OnStart() override;
    void UpdatePosition(uint32_t windowWidth, uint32_t windowHeight);
};
```

### Концепция

- `SetScreenAnchor(sx, sy)` — точка на экране, к которой привязан объект. `(0, 0)` = top-left, `(1, 1)` = bottom-right.
- `SetObjectAnchor(ox, oy)` — точка в объекте, которая привязывается. `(0.5, 0.5)` = центр объекта.
- `SetSize(w, h)` — размер объекта (через `SpriteRenderer::SetCustomSize` или `Transform::SetScale`).

Итоговая позиция = `ScreenAnchor * (windowW, windowH) - ObjectAnchor * (w, h)`.

### Presets

Если установлен пресет, `SetScreenAnchor`/`SetObjectAnchor` перезаписываются:

| Preset | ScreenAnchor | ObjectAnchor |
|---|---|---|
| TopLeft | (0, 0) | (0, 0) |
| TopCenter | (0.5, 0) | (0.5, 0) |
| TopRight | (1, 0) | (1, 0) |
| MiddleLeft | (0, 0.5) | (0, 0.5) |
| MiddleCenter | (0.5, 0.5) | (0.5, 0.5) |
| MiddleRight | (1, 0.5) | (1, 0.5) |
| BottomLeft | (0, 1) | (0, 1) |
| BottomCenter | (0.5, 1) | (0.5, 1) |
| BottomRight | (1, 1) | (1, 1) |
| StretchAll | (0, 0) | (0, 0) + растягивание на весь экран |

### Пересчёт при ресайзе

`Scene::RecalculateAnchors(w, h)` вызывается из `Window::ResizeCallback`. Идёт по всем `Anchor` (зарегистрированным в `OnStart`) и зовёт `UpdatePosition(w, h)`.

## Класс `Button`

**Файл:** `Engine/Include/UI/Button.h`

```cpp
class Button : public Component {
public:
    Button(GameObject* owner);

    void SetSize(const glm::vec2& size);
    void SetOnClick(std::function<void()> callback);
    void SetOnPointerDown(std::function<void()> callback);
    void SetOnPointerUp(std::function<void()> callback);
    void SetOnPointerEnter(std::function<void()> callback);
    void SetOnPointerExit(std::function<void()> callback);

    void OnStart() override;
    void OnUpdate(float deltaTime) override;
};
```

### Использование

```lua
-- В game.lua
local btn = obj:AddComponent_Button()
btn:SetSize(200, 50)
btn:SetOnClick(function() Log("Clicked!") end)
btn:SetOnPointerEnter(function() Log("Hovered") end)
```

### Как работает

1. **`OnStart`:** находит `SpriteRenderer` и `TextRenderer` в том же GameObject (через `GetComponent`).
2. **`OnUpdate`:** каждый кадр проверяет:
   - Положение мыши через `InputSystem::Get().GetMousePosition()`.
   - Попадает ли мышь в AABB объекта (с учётом `m_Size` и текущей `Transform` позиции).
   - Если попадает и ЛКМ нажата — `m_Pressed = true`, вызывает `m_OnPointerDown` (если был только что нажат).
   - Если отпущена внутри — `m_OnClick`.
   - Если вошла/вышла — `m_OnPointerEnter`/`m_OnPointerExit`.
3. **`SyncSize`:** передаёт `m_Size` в `SpriteRenderer::SetCustomSize`.

## Пример из `game.lua`

```lua
local btnObj = scene:CreateUIObject("TestButton")
btnObj:SetZOrder(2)
local bt = btnObj:AddComponent_Transform()

local anchor = btnObj:AddComponent_Anchor()
anchor:SetScreenAnchor(0.5, 0.5)   -- центр экрана
anchor:SetObjectAnchor(0.5, 0.5)   -- центр объекта
anchor:SetPreset(8)                -- MiddleCenter
anchor:SetSize(200, 50)

local bgr = btnObj:AddComponent_SpriteRenderer()
bgr:SetShader(GetShader("SpriteShader", vSrc, fSrc))
bgr:SetTexture(GetTexture("assets/ui/button.png"))
bgr:SetIsUI(true)
bgr:SetAlignment(0.5, 0.5)

local btr = btnObj:AddComponent_TextRenderer()
btr:SetFont(font)
btr:SetText("Click me")
btr:SetFontSize(42)

local button = btnObj:AddComponent_Button()
button:SetSize(200, 50)
button:SetOnClick(function() Log("Button clicked!") end)
```

## Известные ограничения

- ❌ Нет фокуса (Tab/Shift+Tab).
- ❌ Нет скролла внутри Button-области.
- ❌ Hit-test только AABB, без учёта альфа-канала текстуры.
- ❌ Нет disabled-состояния.
- ❌ Нет визуального feedback (hover/pressed) — `m_Hovered` есть, но текстура не меняется.
