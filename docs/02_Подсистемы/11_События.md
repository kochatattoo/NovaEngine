# 11 — События (Event, EventDispatcher)

> **Статус:** 🟢 Стабильно, но не до конца интегрировано в `Application::OnEvent`

**Файлы:** `Engine/Include/Event/Event.h`

## Базовый класс `Event`

```cpp
class Event {
public:
    virtual ~Event() = default;
    virtual EventType GetEventType() const = 0;
    virtual const char* GetName() const = 0;
    virtual std::string ToString() const { return GetName(); }
    bool Handled = false;
};
```

## Типы событий

```cpp
enum class EventType {
    None = 0,
    WindowClose, WindowResize, WindowFocus, WindowLostFocus, WindowMoved,
    KeyPressed, KeyReleased, KeyTyped,
    MouseButtonPressed, MouseButtonReleased, MouseMoved, MouseScrolled
};
```

⚠️ Сейчас реализованы **только** `KeyPressed`, `KeyReleased`, `MouseMoved`, `MouseScrolled`, `MouseButton{Pressed,Released}`. `WindowClose/Resize/...` объявлены, но не используются.

## Конкретные события

```cpp
class KeyPressedEvent : public Event {
public:
    KeyPressedEvent(int keycode, bool repeat = false) : KeyCode(keycode), Repeat(repeat) {}
    int KeyCode;
    bool Repeat;
    EVENT_CLASS_TYPE(KeyPressed)
};

class KeyReleasedEvent : public Event { int KeyCode; EVENT_CLASS_TYPE(KeyReleased) };
class MouseMovedEvent  : public Event { float MouseX, MouseY; EVENT_CLASS_TYPE(MouseMoved) };
class MouseScrolledEvent : public Event { float XOffset, YOffset; EVENT_CLASS_TYPE(MouseScrolled) };
class MouseButtonPressedEvent  : public Event { MouseButton m_Button; EVENT_CLASS_TYPE(MouseButtonPressed) };
class MouseButtonReleasedEvent : public Event { MouseButton m_Button; EVENT_CLASS_TYPE(MouseButtonReleased) };
```

`EVENT_CLASS_TYPE(type)` — макрос, который:
- `static EventType GetStaticType() { return EventType::type; }`
- `virtual EventType GetEventType() const override { return GetStaticType(); }`
- `virtual const char* GetName() const override { return #type; }`

## Диспетчер `EventDispatcher`

```cpp
class EventDispatcher {
public:
    EventDispatcher(Event& event) : m_Event(event) {}

    // Для функций, возвращающих bool (true = событие обработано)
    template<typename T, typename F>
    typename std::enable_if_t<std::is_same_v<bool, std::invoke_result_t<F, T&>>, EventDispatcher&>
        Dispatch(const F& func);

    // Для функций, возвращающих void
    template<typename T, typename F>
    typename std::enable_if_t<std::is_same_v<void, std::invoke_result_t<F, T&>>, EventDispatcher&>
        Dispatch(const F& func);

    // operator() как алиас к Dispatch
    template<typename T, typename F>
    EventDispatcher& operator()(const F& func) {
        return Dispatch<T>(func);
    }
};
```

### Использование

```cpp
EventDispatcher dispatcher(event);
dispatcher.Dispatch<KeyPressedEvent>([this](auto& key) {
    m_KeyJustPressed[static_cast<KeyCode>(key.KeyCode)] = true;
    return true;   // событие обработано
});
dispatcher.Dispatch<MouseMovedEvent>([this](auto& m) {
    m_MousePosition = glm::vec2(m.MouseX, m.MouseY);
    // return void
});
```

## Поток событий

```
Window::WndProc
    ├─ WM_KEYDOWN → make_unique<KeyPressedEvent> → InputSystem::PushEvent
    ├─ WM_KEYUP   → KeyReleasedEvent               → PushEvent
    ├─ WM_MOUSEMOVE → MouseMovedEvent              → PushEvent
    ├─ WM_LBUTTONDOWN/UP → MouseButton{Pressed,Released} → PushEvent
    └─ и т.д.

InputSystem::Update (каждый кадр)
    └─ ProcessEvent(e)
        └─ EventDispatcher(e)
            ├─ Dispatch<KeyPressedEvent> → установить m_KeyJustPressed[key] = true
            ├─ Dispatch<KeyReleasedEvent> → m_KeyJustReleased[key] = true
            ├─ Dispatch<MouseMovedEvent>  → m_MousePosition = (x, y)
            └─ Dispatch<MouseButtonPressedEvent> → m_MouseJustPressed[button] = true
```

## ⚠️ `Application::OnEvent` не вызывается

Сейчас `NK::Application::OnEvent(Event& event)` объявлен, но **нигде не зовётся** в `Engine::Run`. События обрабатываются только в `InputSystem`. **TODO v0.2:** либо пробросить события в `m_App->OnEvent(e)`, либо удалить `OnEvent` (он бесполезен).

## Известные ограничения

- ❌ `EventDispatcher` — единственное место с нетривиальным SFINAE в движке.
- ❌ Window-события (`WindowClose`, `WindowResize`) не реализованы, хотя `Window::WndProc` ловит `WM_CLOSE`/`WM_SIZE`.
- ❌ Нет event queue с приоритетами.
- ❌ Нет propagation control (capture/bubble).
- ❌ Нет `KeyTypedEvent` (для ввода текста в TextBox).
