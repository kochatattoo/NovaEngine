# 04 — Рендерер и камеры (Renderer, Shader, Camera, OrthographicCamera, SpriteRenderer, TextRenderer, Font, Texture2D, VAO/VBO/IBO)

## Renderer

**Файлы:** `Engine/Include/Renderer/Renderer.h`, `Engine/Source/Renderer/Renderer.cpp`

```cpp
class Renderer {
public:
    static void Init();                                  // glEnable(DEPTH_TEST, CULL_FACE)
    static void BeginFrame();                            // glClear
    static void EndFrame();                              // пусто
    static void SetClearColor(float r, float g, float b, float a);
};
```

`Init` вызывается один раз в `Engine::Initialize`. Включает:
```cpp
glEnable(GL_DEPTH_TEST);
glEnable(GL_CULL_FACE);
glDepthFunc(GL_LEQUAL);
glCullFace(GL_BACK);
glFrontFace(GL_CCW);
```

`BeginFrame`:
```cpp
glClearColor(s_ClearColor[0], s_ClearColor[1], s_ClearColor[2], s_ClearColor[3]);
glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
```

`EndFrame` сейчас пустая.

## Shader

**Файлы:** `Engine/Include/Renderer/Shader.h`, `Engine/Source/Renderer/Shader.cpp`

```cpp
class Shader {
public:
    Shader(const std::string& vertexSrc, const std::string& fragmentSrc);
    ~Shader();

    void Bind() const;
    void Unbind() const;

    void SetUniform4f(const std::string& name, float r, float g, float b, float a) const;
    void SetUniformMat4(const std::string& name, const glm::mat4& matrix);
    void SetUniform1i(const std::string& name, int value);

private:
    uint32_t m_RendererID;
    mutable std::unordered_map<std::string, int> m_UniformLocationCache;
};
```

### Использование

```cpp
const char* vSrc = R"(#version 330 core
layout(location = 0) in vec2 a_Position;
layout(location = 1) in vec2 a_TexCoord;
uniform mat4 u_ViewProjection;
uniform mat4 u_Model;
out vec2 v_TexCoord;
void main() {
    gl_Position = u_ViewProjection * u_Model * vec4(a_Position, 0.0, 1.0);
    v_TexCoord = a_TexCoord;
})";

auto shader = std::make_shared<Shader>(vSrc, fSrc);
shader->Bind();
shader->SetUniformMat4("u_ViewProjection", viewProj);
shader->SetUniform1i("u_Texture", 0);
```

### Кэш uniform-локаций

`m_UniformLocationCache` запоминает результат `glGetUniformLocation`.

## Font

**Файлы:** `Engine/Include/Renderer/Font.h`, `Engine/Source/Renderer/Font.cpp`

```cpp
class Font {
public:
    explicit Font(const std::string& filepath);     // .ttf
    ~Font();

    std::shared_ptr<Texture2D> CreateTextTexture(
        const std::string& text, float fontSize,
        uint8_t r = 255, uint8_t g = 255, uint8_t b = 255, uint8_t a = 255);
};
```

- Загружает TTF через `stb_truetype` (`stbtt_InitFont`).
- При создании текстуры:
  1. `stbtt_BakeFontBitmap` — рендерит в bitmap.
  2. Создаёт `Texture2D::CreateFromData` (формат `GL_RED`).

⚠️ **Один шрифт держит только одну текстуру.** Если вызвать `CreateTextTexture` дважды — первая текстура утечёт.

```cpp
class OrthographicCamera {
```

### Две камеры в `Scene`

```cpp
OrthographicCamera m_GameCamera{ -5.0f, 5.0f, -5.0f, 5.0f };      // мир: (-5,-5) → (5,5)
OrthographicCamera m_UICamera {  0.0f, 1280.0f, 720.0f, 0.0f };   // UI:  (0,0) → (1280,720), Y вниз
```

**GameCamera:** левосторонняя система координат. По умолчанию видит мир от -5 до 5. `OnWindowResized(w, h)` — пересчитывает проекцию с сохранением aspect ratio.

**UICamera:** Top-left origin (Y растёт вниз). Размеры = размеры окна.

### `ScreenToWorldPoint` / `ScreenToUIPoint`

Конвертация клиентских пикселей мыши → мировые (или UI) координаты. Используется в `game_match3.lua` для hit-testing по клеткам.

## SpriteRenderer (компонент)

**Файлы:** `Engine/Include/Renderer/SpriteRenderer.h`, `Engine/Source/Renderer/SpriteRenderer.cpp`

```cpp
class SpriteRenderer : public Component {
public:
    SpriteRenderer(GameObject* owner);
    void SetTexture(std::shared_ptr<Texture2D> texture);
    void SetShader(std::shared_ptr<Shader> shader);
    void Render(const glm::mat4& viewProjection);
    void SetAlignment(float hAlign, float vAlign);
    void SetCustomSize(const glm::vec2& size);
    glm::vec2 GetCustomSize() const;
    void SetColor(float r, float g, float b, float a);
    void SetUseColor(bool use);
    void SetIsUI(bool ui);
    void SetPixelsPerUnit(float ppu);
    float GetPixelsPerUnit() const;
};
```

### Как работает рендер

1. **Static unit quad:** в `s_QuadVAO/s_QuadVBO/s_QuadIBO` (один раз) лежит квадрат 1×1 с UV.
2. **Размер в мире:** `m_CustomSize` (если 0 — используется размер текстуры / `m_PixelsPerUnit`).
3. **PPU (Pixels Per Unit):** 100.0f по умолчанию. 1 unit = 100 пикселей.
4. **Model matrix:** `translate(position) * scale(m_CustomSize/2)` (для игрового мира).
5. **Render:**
   - `Shader::Bind`, `Texture2D::Bind(0)`.
   - `shader->SetUniformMat4("u_ViewProjection", viewProjection)`.
   - `shader->SetUniformMat4("u_Model", model)`.
   - `shader->SetUniform1i("u_Texture", 0)`.
   - Если `m_UseColor` — `shader->SetUniform4f("u_Color", …)`, иначе `u_Color = (1, 1, 1, 1)`.
   - `glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, 0)`.
   - `glBindVertexArray(0)`, `Texture2D::Unbind()`, `Shader::Unbind()`.

### ⚠️ v0.1.3 — Transform::SetScale игнорируется в игровом мире

В `SpriteRenderer::Render` для игрового мира (`!m_IsUI`) model matrix **не использует** `transform::GetScale()`. Размер определяется только `m_CustomSize / 2`:

```cpp
if (m_IsUI) {
    model = glm::translate(glm::mat4(1.0f), pos + glm::vec3(renderW * 0.5f, renderH * 0.5f, 0.0f));
    model = glm::scale(model, glm::vec3(renderW * 0.5f, renderH * 0.5f, 1.0f));
}
else {
    // Для игрового мира: просто квадрат вокруг позиции
    model = glm::translate(glm::mat4(1.0f), pos);
    model = glm::scale(model, glm::vec3(renderW * 0.5f, renderH * 0.5f, 1.0f));
}
```

Это значит, что `obj:GetTransform():SetScale(1.2, 1.2)` **не даёт визуального эффекта** для игровых объектов (только `SetCustomSize` работает).

**Следствие для Match3:** плитки создаются через `CreateSolidColorTexture(255, 0, 0, 255)` — это 1x1 пиксель. С `m_PixelsPerUnit=100` и `m_CustomSize=0`: `renderW = 1 / 100 = 0.01` мировых единиц = **1 пиксель** на экране. Плитки видны как цветные пиксели, не как "кубики".

**Решение (v0.1.3):** в `OnTileChanged` callback в `game_match3.lua` добавить:
```lua
sr:SetCustomSize(CELL_SIZE / PPU, CELL_SIZE / PPU)  -- 0.64 x 0.64 мировых единиц
sr:SetPixelsPerUnit(PPU)
```

И добавить биндинги в `LuaComponentBindings.cpp`:
```cpp
"SetCustomSize", [](SpriteRenderer& sr, double w, double h) { sr.SetCustomSize((float)w, (float)h); },
"SetPixelsPerUnit", [](SpriteRenderer& sr, double ppu) { sr.SetPixelsPerUnit((float)ppu); },
```

**TODO v0.2:** либо использовать `transform::GetScale()` в model matrix (правильнее), либо пометить `SetScale` для игрового мира как deprecated.

### Alignment

`m_HAlign`/`m_VAlign` (0..1) сдвигают вершины в пределах `m_CustomSize`:
- `hAlign = 0.5` → объект центрирован по X.
- `hAlign = 0.0, vAlign = 0.0` → top-left.

**Файлы:** `Engine/Include/Renderer/TextRenderer.h`, `Engine/Source/Renderer/TextRenderer.cpp`

```cpp
class TextRenderer : public Component {
public:
    TextRenderer(GameObject* owner);
    void SetFont(std::shared_ptr<Font> font);
    void SetText(const std::string& text);
    void SetFontSize(float size);
    void SetColor(uint8_t r, uint8_t g, uint8_t b, uint8_t a = 255);
```

При `SetText` / `SetFontSize` / `SetColor` выставляется `m_TextChanged = true`. В `OnStart` и каждый `Render`, если `m_TextChanged`, вызывается `UpdateTexture`.

### ⚠️ Проблема с многократным re-bake

Если в одной сцене два `TextRenderer` используют один `Font`, второй BakeFontBitmap затирает текстуру первого. Workaround — давать каждому `TextRenderer` свой `Font`.

## Сводка по uniform-контрактам

| Uniform | Тип | Ожидается в |
|---|---|---|
| `u_ViewProjection` | `mat4` | всех рендерерах |
| `u_Model` | `mat4` | всех рендерерах |
| `u_Texture` | `sampler2D` (int 0) | `SpriteRenderer`, `TextRenderer` |
| `u_Color` | `vec4` | `SpriteRenderer`, `TextRenderer` (умножается на тексель) |

Default-шейдер (`"DefaultSprite"`) регистрируется в `Engine::Initialize`.

### DefaultSprite шейдер (v0.1.2)

```cpp
const std::string defaultV = R"(#version 330 core
layout(location = 0) in vec2 a_Position;
layout(location = 1) in vec2 a_TexCoord;
uniform mat4 u_ViewProjection;
uniform mat4 u_Model;
uniform vec4 u_Color;
out vec2 v_TexCoord;
void main() {
    gl_Position = u_ViewProjection * u_Model * vec4(a_Position, 0.0, 1.0);
    v_TexCoord = a_TexCoord;
})";

const std::string defaultF = R"(#version 330 core
in vec2 v_TexCoord;
out vec4 FragColor;
uniform sampler2D u_Texture;
uniform vec4 u_Color;
void main() {
    vec4 texColor = texture(u_Texture, v_TexCoord);
    // u_Color умножается на тексель — белый (1,1,1,1) = без изменений.
    FragColor = texColor * u_Color;
})";
```

**v0.1.2:** добавлен `uniform vec4 u_Color` в оба шейдера, fragment умножает `texColor * u_Color`. До этого `SpriteRenderer::SetColor` устанавливал uniform, но шейдер его игнорировал (uniform не существовал) — `SetColor` не давал визуального эффекта. Теперь работает.

## Известные ограничения

- ❌ Нет batching'а — каждый спрайт = отдельный `glDrawElements` (на 100 спрайтах = 100 draw calls).
- ❌ Нет instanced rendering.
- ❌ Layout вершин зашит (position vec2 + texcoord vec2).
- ❌ `Font` не кэширует bitmap.
- ❌ `OrthographicCamera` не поддерживает zoom (масштабирование).
