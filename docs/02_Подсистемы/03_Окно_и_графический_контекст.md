# 03 — Окно и графический контекст (Window, GraphicsContext)

> **Статус:** 🟢 Стабильно, но платформо-зависимо (только Windows)

**Файлы:**
- `Engine/Include/Window/Window.h`, `Engine/Source/Window/Window.cpp`
- `Engine/Include/Renderer/GraphicsContext.h`, `Engine/Source/Renderer/GraphicsContext.cpp`

Два класса тесно связаны: `Window` создаёт HWND и `GraphicsContext` поверх него. Цель — **инкапсулировать** платформенные детали так, чтобы остальной движок говорил `ctx->MakeCurrent()` и не думал про WGL.

## Класс `Window`

**Файл:** `Engine/Include/Window/Window.h`

```cpp
struct WindowProperties {
    std::string Title;
    uint32_t Width;
    uint32_t Height;
};

class Window {
public:
    explicit Window(const WindowProperties& props);
    ~Window();

    void OnUpdate();                                     // PeekMessage
    bool ShouldClose() const;

    void* GetNativeWindow() const;                       // HWND
    uint32_t GetWidth() const;
    uint32_t GetHeight() const;
    GraphicsContext* GetGraphicsContext();

    void GetMouseClientPosition(int& outX, int& outY);
    std::function<void(uint32_t, uint32_t)> ResizeCallback;
};
```

### Инициализация (`Window::Init`)

1. `GetModuleHandle(nullptr)` → `hInstance`.
2. Регистрация `WNDCLASS`:
   ```cpp
   const wchar_t CLASS_NAME[] = L"NK_WINDOW_CLASS";
   WNDCLASS wc = {};
   wc.lpfnWndProc   = Window::WndProc;
   wc.hInstance     = hInstance;
   wc.lpszClassName = CLASS_NAME;
   wc.style         = CS_HREDRAW | CS_VREDRAW;
   wc.hCursor       = LoadCursor(nullptr, IDC_ARROW);
   RegisterClass(&wc);
   ```
3. UTF-8 → UTF-16 для заголовка (через `MultiByteToWideChar`).
4. `CreateWindowEx(WS_OVERLAPPEDWINDOW, ..., this)` — `lpCreateParams = this`.
5. `ShowWindow(m_Hwnd, SW_SHOW)`.
6. `m_GraphicsContext = GraphicsContext::Create(m_Hwnd)`.
7. `m_GraphicsContext->Init(m_Hwnd)`.

### `WndProc` — оконная процедура

Статическая функция-член. Через `WM_NCCREATE` сохраняет `this` в `GWLP_USERDATA`, далее достаёт его для всех сообщений. Обрабатывает:

| Сообщение | Действие |
|---|---|
| `WM_CLOSE` | `m_ShouldClose = true` |
| `WM_SIZE` | обновить `m_Data.Width/Height`, вызвать `ResizeCallback` |
| `WM_KEYDOWN` | `InputSystem::Get().PushEvent(KeyPressedEvent(wParam, repeat))` |
| `WM_KEYUP` | `PushEvent(KeyReleasedEvent(wParam))` |
| `WM_MOUSEMOVE` | `PushEvent(MouseMovedEvent(LOWORD, HIWORD))` |
| `WM_LBUTTONDOWN/UP` | `PushEvent(MouseButton{Pressed,Released}(Left))` |
| `WM_RBUTTONDOWN/UP` | то же Right |
| `WM_MBUTTONDOWN/UP` | то же Middle |
| `WM_MOUSEWHEEL` | `PushEvent(MouseScrolledEvent(0, delta/WHEEL_DELTA))` |

Все остальные сообщения → `DefWindowProc`.

### `OnUpdate`

```cpp
void Window::OnUpdate() {
    MSG msg;
    while (PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE)) {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
    }
}
```

### `GetMouseClientPosition`

```cpp
POINT pt;
GetCursorPos(&pt);          // экранные
ScreenToClient(m_Hwnd, &pt); // → клиентские
outX = pt.x; outY = pt.y;
```

### `ResizeCallback`

Назначается в `Engine::Initialize`:
```cpp
m_Window->ResizeCallback = [this](uint32_t w, uint32_t h) {
    m_Scene.GetGameCamera().OnWindowResized(w, h);
    m_Scene.GetUICamera().SetProjection(0.0f, (float)w, (float)h, 0.0f);
    glViewport(0, 0, w, h);
    m_Scene.RecalculateAnchors(w, h);
};
```

## Класс `GraphicsContext`

**Файл:** `Engine/Include/Renderer/GraphicsContext.h`

Абстракция платформенного GL-контекста. Цель — кроссплатформенность (сейчас только Windows).

```cpp
class GraphicsContext {
public:
    virtual ~GraphicsContext() = default;
    virtual void Init(void* nativeWindow) = 0;
    virtual void MakeCurrent() = 0;
    virtual void SwapBuffers() = 0;
    virtual void Shutdown() = 0;

    static GraphicsContext* Create(void* nativeWindow);
};
```

### Реализация `WindowsOpenGLContext`

1. **`Init(HWND)`:**
   - `ChoosePixelFormat` + `SetPixelFormat` (стандартный PFD).
   - Создать **временный** контекст `wglCreateContext(hdc)`, сделать current.
   - Через `wglGetProcAddress("wglCreateContextAttribsARB")` получить расширение.
   - Создать **постоянный** контекст с атрибутами: `WGL_CONTEXT_MAJOR_VERSION_ARB=3`, `WGL_CONTEXT_MINOR_VERSION_ARB=3`, `WGL_CONTEXT_PROFILE_MASK_ARB=WGL_CONTEXT_CORE_PROFILE_BIT_ARB`.
   - Удалить временный, активировать постоянный.
   - **Вручную загрузить все GL-функции** через `GetAnyGLFuncAddress(name)`.

2. **`MakeCurrent()`:** `wglMakeCurrent(hdc, m_Context)`.
3. **`SwapBuffers()`:** `SwapBuffers(hdc)`.
4. **`Shutdown()`:** `wglDeleteContext(m_Context)`.

### Ручная загрузка GL-функций

```cpp
inline void* GetAnyGLFuncAddress(const char* name) {
    void* p = (void*)wglGetProcAddress(name);
    if (!p || p == (void*)0x1 || p == (void*)0x2 || p == (void*)0x3 || p == (void*)-1) {
        HMODULE mod = GetModuleHandleA("opengl32.dll");
        p = (void*)GetProcAddress(mod, name);
    }
    return p;
}
```

Затем в `Init` для каждой используемой функции:
```cpp
glad_glViewport = (PFNGLVIEWPORTPROC) GetAnyGLFuncAddress("glViewport");
glad_glClear    = (PFNGLVIEWPORTPROC) GetAnyGLFuncAddress("glClear");
// ... и т.д.
```

Полный список — в `Engine/Source/Renderer/GraphicsContext.cpp`.

### Почему так

- **Полный контроль:** видно, какие GL-функции реально используются.
- **Нет зависимости от glad-loader.**
- **Минус:** при добавлении новой GL-функции — нужно вручную прописать загрузку.

## Известные ограничения

- ❌ Только Windows.
- ❌ Один GL-контекст на приложение. Несколько окон не поддерживаются.
- ❌ Нет проверки расширений.
- ❌ Если `wglCreateContextAttribsARB` не доступен (видеокарта < 2010), инициализация упадёт.
