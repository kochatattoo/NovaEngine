# 07 — Ввод (Input, InputSystem, KeyCodes)

> **Статус:** 🟢 Стабильно, есть две параллельные системы (legacy Input + событийный InputSystem)

**Файлы:**
- `Engine/Include/Input/KeyCode/KeyCodes.h`
- `Engine/Include/Input/Input.h`, `Engine/Source/Input/Input.cpp`
- `Engine/Include/Input/InputSystem.h`, `Engine/Source/Input/InputSystem.cpp`

В движке сосуществуют **две** системы ввода:

1. **`Input`** — старый, простой, статический опрос через WinAPI (`GetAsyncKeyState`).
2. **`InputSystem`** — новый, событийный: `Window::WndProc` кладёт события в очередь, `InputSystem::Update` их разбирает, состояния клавиш/мыши кэшируются.

В `InputSystem::GetKey` для обратной совместимости внутри всё ещё используется `Input::IsKeyDown` (TODO v0.2 — убрать зависимость).

## KeyCodes / MouseButton

**Файл:** `Engine/Include/Input/KeyCode/KeyCodes.h`

```cpp
enum class KeyCode : uint32_t {

    // Функциональные
    F1 = VK_F1, …, F12 = VK_F12,
    // Стрелки
    Left = VK_LEFT, Right = VK_RIGHT, Up = VK_UP, Down = VK_DOWN,
    // Управление
    Space = VK_SPACE, Escape = VK_ESCAPE, Enter = VK_RETURN,
    Tab = VK_TAB, Backspace = VK_BACK,
    Insert = VK_INSERT, Delete = VK_DELETE,
    Home = VK_HOME, End = VK_END,
    PageUp = VK_PRIOR, PageDown = VK_NEXT,
    CapsLock = VK_CAPITAL, NumLock = VK_NUMLOCK, ScrollLock = VK_SCROLL,
    PrintScreen = VK_SNAPSHOT, Pause = VK_PAUSE,
    // Модификаторы
    LeftShift = VK_LSHIFT, LeftControl = VK_LCONTROL, LeftAlt = VK_LMENU,
    RightShift = VK_RSHIFT, RightControl = VK_RCONTROL, RightAlt = VK_RMENU,
```

## `Input` (legacy, статический опрос)

**Файл:** `Engine/Include/Input/Input.h`

```cpp
class Input {

    static bool IsKeyDown(int rawKey);

```

Реализация использует `GetAsyncKeyState` (текущее состояние без буфера).

## `InputSystem` (новое, событийное)

**Файл:** `Engine/Include/Input/InputSystem.h`

```cpp
class InputSystem {
public:
    static InputSystem& Get();

    void Update();  // разобрать очередь событий
    void PushEvent(std::unique_ptr<Event> event);

    // Клавиши
    bool GetKey(KeyCode key) const;       // удерживается
    bool GetKeyDown(KeyCode key) const;   // только что нажата
    bool GetKeyUp(KeyCode key) const;     // только что отпущена

    // Кнопки мыши
    bool GetMouseButton(MouseButton button) const;
    bool GetMouseButtonDown(MouseButton button) const;
    bool GetMouseButtonUp(MouseButton button) const;

    // Позиция мыши
    glm::vec2 GetMousePosition() const;
};
```

### Как работает

1. `Window::WndProc` ловит `WM_KEYDOWN`/`WM_KEYUP`/`WM_MOUSEMOVE`/и т.д.
2. Создаёт `KeyPressedEvent`/`KeyReleasedEvent`/… и зовёт `InputSystem::Get().PushEvent(std::move(event))`.
3. Каждый кадр `Engine::Run` вызывает `InputSystem::Get().Update()` после `m_Window->OnUpdate()`.
4. `Update()` разбирает очередь, заполняет:
   - `m_KeyJustPressed[KeyCode]` = true (на этот кадр).
   - `m_KeyJustReleased[KeyCode]` = true.
   - `m_MousePosition` = (x, y).
5. В конце кадра `ResetOneShotStates()` — сбрасывает `JustPressed`/`JustReleased` (но не сами состояния клавиш).
6. **Сами** состояния клавиш (`удерживается ли`) берутся через `Input::IsKeyDown` (legacy).

### ✅ Сделано в v0.1.1

`InputSystem` теперь **полностью автономен** — не зависит от `Input::IsKeyDown` и `Input::GetMouseButton`.

**Изменения:**
- Добавлены `m_KeysHeld: unordered_map<KeyCode, bool>` и `m_MouseButtonsHeld: unordered_map<MouseButton, bool>`.
- В `ProcessEvent` обновляются:
  - `KeyPressedEvent` → `m_KeysHeld[k] = true` + `m_KeyJustPressed[k] = true`
  - `KeyReleasedEvent` → `m_KeysHeld[k] = false` + `m_KeyJustReleased[k] = true`
  - `MouseButtonPressedEvent` → `m_MouseButtonsHeld[b] = true` + `m_MouseJustPressed[b] = true`
  - `MouseButtonReleasedEvent` → `m_MouseButtonsHeld[b] = false` + `m_MouseJustReleased[b] = true`
- `GetKey` / `GetMouseButton` возвращают значение из `m_KeysHeld` / `m_MouseButtonsHeld`.
- `#include "Input/Input.h"` из `InputSystem.cpp` убран — больше не нужен.

**Что осталось:**
- `Input.h` (legacy) сохранён для обратной совместимости, но новый код должен использовать только `InputSystem`.

### ✅ Сделано в v0.1.2

**Mouse wheel кэширование** — раньше `MouseScrolledEvent` создавался в `Window::WndProc`, но `InputSystem` его не обрабатывал. Теперь:

- Добавлено `m_MouseScroll: glm::vec2` (по умолчанию `(0, 0)`).
- В `ProcessEvent` суммируется дельта: `m_MouseScroll += glm::vec2(scroll.XOffset, scroll.YOffset)`.
- Добавлен `glm::vec2 GetMouseScroll() const` — возвращает дельту за текущий кадр.
- Сбрасывается в `ResetOneShotStates()`.

**Использование из C++:**
```cpp
glm::vec2 scroll = InputSystem::Get().GetMouseScroll();
if (scroll.y > 0) {
    // колесо вверх
}
```

**Использование из Lua:** пока не проброшено (TODO v0.2 — добавить `GetMouseScroll()` в `LuaInputBindings`).

## Использование из C++

```cpp
// В игре
if (Input::IsKeyDown(KeyCode::Escape)) {
    Engine::Get().Shutdown();
}

if (InputSystem::Get().GetMouseButtonDown(MouseButton::Left)) {
    // только что нажата ЛКМ
}
```

## Использование из Lua

### Через `LuaInputBindings`

```lua
-- Глобальные enum'ы
KeyCode.Space, KeyCode.Escape, …
MouseButton.Left, MouseButton.Right, MouseButton.Middle

-- Клавиши
if GetKey(KeyCode.Space) then … end      -- удерживается
if GetKeyDown(KeyCode.Space) then … end  -- только что нажата
if GetKeyUp(KeyCode.Space) then … end    -- только что отпущена

-- Мышь
if GetMouseButton(MouseButton.Left) then … end
if GetMouseButtonDown(MouseButton.Left) then … end
local x, y = GetMousePos()                -- (lua tuple)
```

### Через `LuaFuncBindings` (legacy API)

```lua
if IsKeyDown(32) then … end              -- VK_SPACE = 32
if IsMouseButtonDown(1) then … end       -- VK_LBUTTON = 1
local x, y = GetMousePosition()
```

`LuaInputBindings` — новый API (с типизированными enum'ами). `LuaFuncBindings` — старые функции (принимают int).

## Грабли

- **Двойная запись API:** есть и `IsKeyDown` (legacy), и `GetKey` (новый). В коде стоит придерживаться `GetKey/Down/Up` (InputSystem).
- **`Input::IsKeyDown` отдаёт состояние в момент вызова** (через `GetAsyncKeyState`), а `InputSystem::GetKey` — состояние, обновлённое в `Update()`. Если вызвать между кадрами — рассинхрон.
- **В Headless-режиме** (без окна) `Input::IsKeyDown` вернёт `false` (нет HWND).
- **Mouse wheel** — `MouseScrolledEvent` сразу сбрасывается (`XOffset=0`, `YOffset=±1`). В InputSystem **не кэшируется** (TODO).
