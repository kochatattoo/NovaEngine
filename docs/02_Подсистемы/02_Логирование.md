# 02 — Логирование (Log / Logger)

> **Статус:** 🟢 Стабильно

**Файлы:** `Engine/Include/Core/Log.h`, `Engine/Source/Core/Log.cpp`

Простая система логирования с двумя каналами (Core и Client) и пятью уровнями. Полностью header-driven: макросы `NK_INFO(...)` и `NK_CORE_INFO(...)` — основной способ логирования.

## Уровни

```cpp
enum class LogLevel {
    Trace,      // всё подряд (по умолчанию)
    Info,       // обычные сообщения
    Warn,       // предупреждения
    Error,      // ошибки (не фатальные)
    Critical    // критические (фатальные)
};
```

## Два канала

```cpp
class Log {
public:
    static Logger& GetCoreLogger();   // ядро движка
    static Logger& GetClientLogger(); // клиентский код (игра)
private:
    static Logger s_CoreLogger;
    static Logger s_ClientLogger;
};
```

`Logger::SetLevel(level)` — задать минимальный уровень. По умолчанию `Trace`.

## Макросы

```cpp
// Core (код движка)
#define NK_CORE_TRACE(...)    ::NK::Log::GetCoreLogger().Trace(__VA_ARGS__)
#define NK_CORE_INFO(...)     ::NK::Log::GetCoreLogger().Info(__VA_ARGS__)
#define NK_CORE_WARN(...)     ::NK::Log::GetCoreLogger().Warn(__VA_ARGS__)
#define NK_CORE_ERROR(...)    ::NK::Log::GetCoreLogger().Error(__VA_ARGS__)
#define NK_CORE_CRITICAL(...) ::NK::Log::GetCoreLogger().Critical(__VA_ARGS__)

// Client (игра/скрипты)
#define NK_TRACE(...)         ::NK::Log::GetClientLogger().Trace(__VA_ARGS__)
#define NK_INFO(...)          ::NK::Log::GetClientLogger().Info(__VA_ARGS__)
#define NK_WARN(...)          ::NK::Log::GetClientLogger().Warn(__VA_ARGS__)
#define NK_ERROR(...)         ::NK::Log::GetClientLogger().Error(__VA_ARGS__)
#define NK_CRITICAL(...)      ::NK::Log::GetClientLogger().Critical(__VA_ARGS__)
```

## Использование

```cpp
NK_CORE_INFO("Engine constructor");
NK_CORE_TRACE("ResourcePool: loading '%s'", key.c_str());
NK_INFO("Sandbox shutting down.");
NK_WARN("AddUIObject not fully implemented, use CreateUIObject instead");
```

## Реализация

`Logger::PrintLog` использует `va_list` + `vprintf`. Формат — стандартный printf-style. В консоль выводится:

```
[NK][LEVEL] message
```

`SetConsoleOutputCP(CP_UTF8)` вызывается в `Engine::Initialize`, чтобы лог не ломал кириллицу.

## Из Lua

В `LuaFuncBindings` зарегистрирована глобальная функция `Log(msg)`:

```lua
Log("Hello from Lua!")
-- → [NK][INFO] Hello from Lua!
```

## Известные ограничения

- ❌ Нет записи в файл.
- ❌ Нет цветного вывода в консоль.
- ❌ Нет временных меток (только порядок).
- ❌ `Logger` — **не потокобезопасен**.
