# 09 — Ресурсы (ResourceManager, ResourcePool)

> **Статус:** 🟢 Стабильно, базовый кэш

**Файлы:**
- `Engine/Include/Resource/ResourceManager.h`, `Engine/Source/Resource/ResourceManager.cpp`
- `Engine/Include/Resource/ResourcePool.h`

## Класс `ResourcePool<T>`

**Файл:** `Engine/Include/Resource/ResourcePool.h`

Шаблонный кэш по строковому ключу. Сейчас обёртка над `std::unordered_map<std::string, std::shared_ptr<T>>`.

```cpp
template<typename T>
class ResourcePool {
public:
    template<typename... Args>
    std::shared_ptr<T> Get(const std::string& key, Args&&... args);

    std::shared_ptr<T> GetCached(const std::string& key);

    void Put(const std::string& key, std::shared_ptr<T> resource);

    void Remove(const std::string& key);
    void Clear();
    bool Contains(const std::string& key) const;

private:
    std::unordered_map<std::string, std::shared_ptr<T>> m_Resources;
};
```

### Использование

```cpp
ResourcePool<Texture2D> textures;

auto tex1 = textures.Get("assets/textures/player.png");  // загрузит + закэширует
auto tex2 = textures.Get("assets/textures/player.png");  // вернёт из кэша
assert(tex1.get() == tex2.get());

textures.Clear();  // освободить все
```

## Класс `ResourceManager`

**Файл:** `Engine/Include/Resource/ResourceManager.h`

Обёртка над двумя пулами — `Texture2D` и `Shader`. Владеет `Engine`.

```cpp
class ResourceManager {
public:
    std::shared_ptr<Texture2D> GetTexture(const std::string& filepath);

    std::shared_ptr<Shader> GetShader(const std::string& name,
        const std::string& vertexSrc,
        const std::string& fragmentSrc);

    std::shared_ptr<Shader> GetShader(const std::string& name);

    ResourcePool<Shader>& GetShaderPool();

    void ClearAll();
};
```

### Доступ из C++

```cpp
auto& rm = Engine::Get().GetResourceManager();
auto tex = rm.GetTexture("assets/textures/player.png");
auto shader = rm.GetShader("SpriteShader", vSrc, fSrc);
```

### Доступ из Lua

```lua
local tex = GetTexture("assets/textures/player.png")
local shader = GetShader("SpriteShader_final", vertexSrc, fragmentSrc)
```

⚠️ **Ключ шейдера формируется как `"SpriteShader_" + hash(vSrc + fSrc)`** (если переданы обе строки). Это сделано, чтобы уникальный шейдер = уникальный ключ. **TODO v0.2:** убрать автохэш, использовать переданное имя напрямую.

### `GetShader` без исходников

```cpp
std::shared_ptr<Shader> GetShader(const std::string& name);
```

Берёт уже закэшированный по имени. Если нет — `nullptr`.

## `DefaultSprite` шейдер

В `Engine::Initialize` после `SetupLuaBindings`:

```cpp
const std::string defaultV = R"(#version 330 core
layout(location = 0) in vec2 a_Position;
layout(location = 1) in vec2 a_TexCoord;
uniform mat4 u_ViewProjection;
uniform mat4 u_Model;
out vec2 v_TexCoord;
void main() {
    gl_Position = u_ViewProjection * u_Model * vec4(a_Position, 0.0, 1.0);
    v_TexCoord = a_TexCoord;
})";

const std::string defaultF = R"(#version 330 core
in vec2 v_TexCoord;
out vec4 FragColor;
uniform sampler2D u_Texture;
void main() {
    FragColor = texture(u_Texture, v_TexCoord);
})";

auto defaultShader = std::make_shared<Shader>(defaultV, defaultF);
m_ResourceManager.GetShaderPool().Put("DefaultSprite", defaultShader);
```

Используется, если игра не задала свой шейдер.

## Известные ограничения

- ❌ Нет асинхронной загрузки (всё синхронно).
- ❌ Нет автоматической выгрузки неиспользуемых ресурсов (только `ClearAll`).
- ❌ Нет подсчёта ссылок / soft references.
- ❌ Нет хотрелоада.
- ❌ `GetShader` с автохэшем — неудобно (см. выше).
- ❌ Нетривиальный путь к файлу (например, "assets/textures/player.png" — абсолютный относительно CWD, не Assets Root).
