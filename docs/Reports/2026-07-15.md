## Ключевые уроки

1. **PowerShell + кириллица = боль.** 3 файла документации не записались в первый проход (13 июля) из-за проблем с кодировкой путей в bash. Сейчас (15 июля) bash через .NET API показал, что файлы отсутствуют. Урок: всегда проверять результат через `Get-ChildItem` или `.NET Directory.GetFiles`.
2. **legacy Input остался, но `InputSystem` теперь самостоятелен.** Это позволит в v0.2 легко выпилить `Input.h` без боязни сломать что-то в InputSystem.
3. **`OnEvent` был мёртвым кодом 2 недели.** Документация его упоминала, но никто не реализовал проброс. Лучше удалить, чем оставлять «обещание». План по реализации — v0.2.
4. **`Mix` мог зациклиться.** Теоретический баг — `HasPossibleMoves` мог всегда возвращать false (особенно если `FillRandom` оставлял мало вариантов). Safety limit 50 + warning — простой и надёжный фикс.
5. **Дублирование биндингов в `Match3Game` указывает на плохую структуру.** В идеале `Match3Game` не должен знать про `GetMousePosition` и т.п. — это всё уже в `LuaFuncBindings`. Сейчас Match3Game регистрирует только специфику (`Match3Board` + `CreateSolidColorTexture`), что правильно.
