### 1. `InputSystem` — кэширование mouse wheel

**Файлы:** `D:\ENGINE\NovaEngine\Engine\Include\Input\InputSystem.h`, `D:\ENGINE\NovaEngine\Engine\Source\Input\InputSystem.cpp`

**Проблема:** `Window::WndProc` создавал `MouseScrolledEvent` и пушил в очередь, но `InputSystem` его **не обрабатывал** — дельта терялась. Игры не могли узнать про scroll.

**Решение:**
```cpp
// InputSystem.h
glm::vec2 GetMouseScroll() const;

// m_MouseScroll — накопительная дельта за кадр
glm::vec2 m_MouseScroll = glm::vec2(0.0f);

// InputSystem.cpp — ProcessEvent
.Dispatch<MouseScrolledEvent>([this](auto& scroll) {
    m_MouseScroll += glm::vec2(scroll.XOffset, scroll.YOffset);
});

// InputSystem.cpp — ResetOneShotStates
m_MouseScroll = glm::vec2(0.0f);
```

**Тест из C++:**
```cpp
glm::vec2 scroll = InputSystem::Get().GetMouseScroll();
if (scroll.y > 0) {
    // колесо вверх
}
```

### 2. `DefaultSprite` — добавлен `u_Color` uniform

**Файл:** `D:\ENGINE\NovaEngine\Engine\Engine.cpp`

**Проблема:** `SpriteRenderer::SetColor(r, g, b, a)` устанавливал `u_Color` через `SetUniform4f`, но default шейдер **не имел этого uniform** — SetColor не давал визуального эффекта (а в логе могло быть `GL_INVALID_OPERATION` или просто тихо игнорировалось).

**Решение — добавлен `u_Color` в оба шейдера:**
```glsl
// Vertex
uniform vec4 u_Color;
out vec2 v_TexCoord;
void main() {
    gl_Position = u_ViewProjection * u_Model * vec4(a_Position, 0.0, 1.0);
    v_TexCoord = a_TexCoord;
}

// Fragment
uniform sampler2D u_Texture;
uniform vec4 u_Color;
void main() {
    vec4 texColor = texture(u_Texture, v_TexCoord);
    // u_Color умножается на тексель — белый (1,1,1,1) = без изменений.
    FragColor = texColor * u_Color;
}
```

`SpriteRenderer::Render` уже корректно устанавливает `u_Color` (белый по умолчанию, или `m_Color` если `m_UseColor=true`).

**Тест:** в `game.lua` можно вызвать `bgr:SetColor(1, 0, 0, 0.5)` — кнопка станет полупрозрачной красной. **Раньше не работало**.

## Ключевые уроки

1. **`u_Color` в default шейдере был упущением изначально.** `SpriteRenderer` правильно устанавливал uniform, но шейдер его игнорировал — фигня, которую легко не заметить, потому что код не падает. В v0.1.2 это исправлено — теперь `SetColor` действительно влияет на отрисовку.
2. **Mouse wheel кэширование было тривиально** (5 строк кода), но при этом критично для любой игры, где есть scrollable UI или зум камеры. Сейчас, после v0.2, можно будет подключить zoom к `OrthographicCamera::GetMouseScroll().y`.
3. **Документация в OneDrive vs в репо — выбрали репо.** OneDrive остаётся зеркалом. Дальше — обновлять оба места при каждом изменении (или отказаться от OneDrive).
4. **Permission model PowerShell на Windows — нет постоянного allowAlways для `Edit`/`Write` в OneDrive.** Каждый раз нужно подтверждение. Bash с `allowAlways` работает надёжнее.
