## Архитектурные решения

### Почему name-based lookup?

EnTT использует 32-битные `entt::entity` — сохранять их в Lua неудобно (raw integers). Строковые имена дают:
- Lua: `world:GetEntityByName("player_main")` без `entityID` переменных.
- Редактор: иерархия entity.
- Системы: найти конкретную entity по имени (например, `Match3System` ищет `"tile_3_5"`).

### Почему `Match3System` рядом с `Match3Board`?

`Match3Board` (POD-логика) — оставлен для reference и обратной совместимости. `Match3System` — новый класс, owns grid + entities. Постепенно:
- v0.2.3–v0.2.5: Match3System активен, Match3Board мёртвый код.
- v0.2.7: Match3Board удаляется.

### Почему `GetBoard()` вместо `Match3Board.new()`?

- `Match3System` requires `World&` (не может существовать без World) — Lua не имеет прямого доступа к World.
- `Match3Game` owns World + System — он контролирует жизненный цикл.
- Lua получает указатель через `GetBoard()` — это явный dependency injection.

### Почему `Match3Board` остался в Lua API?

`BindClass<Match3System>("Match3Board", ...)` — alias для обратной совместимости. Lua-скрипт, который пишет `board:Swap(...)`, продолжает работать без изменений. Это позволяет мигрировать постепенно.

### Почему рендер НЕ на ECS (пока)?

`SpriteRenderSystem` — отдельная задача v0.2.6. На текущем этапе:
- ECS хранит данные плиток (grid + entities с Transform/Sprite).
- Lua в `OnTileChanged` callback по-прежнему создаёт Scene::GameObject'ы для визуализации.
- Это двойное хранение, но оно позволяет мигрировать логику и рендер независимо.

## Уроки

1. **Namespace `entt` — top-level**, не `NK::ECS::entt`. Ошибка: `entt::entity` работает.
2. **EnTT include path = `Libraries/EnTT/`**, не `Libraries/EnTT/EnTT/`. Include: `<entt/entt.hpp>`, не `<EnTT/entt/entt.hpp>`.
3. **Порядок Start() важен:** сначала RunScript + OnStart (Lua ставит OnTileChanged), потом System::Start (спавнит entities). Иначе первые 100 событий потеряются.
4. **`sol::no_constructor` + `BindClass<T>("name")`** — позволяет биндить C++-only классы под любым именем в Lua.
